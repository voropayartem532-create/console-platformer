# Гра платформер

Консольна гра-платформер. Гравець проходить рівні, долає перешкоди, збирає монетки та бонуси, уникає ворогів і намагається дістатися до фінішу.

## Основні функції

- Консольний рендер рівнів
- Рух персонажа (ліворуч/праворуч, стрибок)
- Система здоров'я та життів
- Платформи різної висоти та ширини
- Вороги, що рухаються
- Збір монеток і бонусів
- Підрахунок очок
- Кілька рівнів
- Меню (старт / вихід / правила)
- Збереження прогресу (опціонально)
- Умови перемоги та поразки
